## Basic Notes

What is Introduction to Backtracking?
- `Introduction to Backtracking` focuses on exploring candidate solutions and undoing choices when constraints fail.
- Performance depends on pruning effectiveness and the quality of state representation.

Core theory details:
- Backtracking = choose, explore, un-choose pattern.
- Searches solution space systematically.
- Pruning invalid states is critical.

Why this matters for hands-on coding:
- Implement one clean Python version and one equivalent Java version.
- Test normal, boundary, and edge cases; then document time/space complexity.
