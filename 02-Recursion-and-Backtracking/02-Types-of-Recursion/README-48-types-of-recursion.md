## Basic Notes

What is Types of Recursion?
- `Types of Recursion` explains how a function solves a problem by reducing it into smaller subproblems.
- Correctness depends on a valid base case, progress toward termination, and controlled stack usage.

Core theory details:
- Types differ by call position and branching factor.
- Knowing the type helps predict complexity.
- Use type awareness for optimization decisions.

Why this matters for hands-on coding:
- Implement one clean Python version and one equivalent Java version.
- Test normal, boundary, and edge cases; then document time/space complexity.
