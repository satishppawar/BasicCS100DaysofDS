## Basic Notes

What is Nested Recursion?
- `Nested Recursion` explains how a function solves a problem by reducing it into smaller subproblems.
- Correctness depends on a valid base case, progress toward termination, and controlled stack usage.

Core theory details:
- Recursive call appears inside another recursive call.
- Harder to reason about and debug.
- Validate base behavior with small inputs first.

Why this matters for hands-on coding:
- Implement one clean Python version and one equivalent Java version.
- Test normal, boundary, and edge cases; then document time/space complexity.
