## Basic Notes

What is Recursive Case?
- `Recursive Case` is a core DSA topic used to reason about correctness and efficiency.
- Focus on clear state, transitions, edge cases, and complexity trade-offs during implementation.

Core theory details:
- Recursive case reduces problem toward base case.
- Progress must be monotonic (problem size shrinks).
- Avoid side effects that break reasoning.

Why this matters for hands-on coding:
- Implement one clean Python version and one equivalent Java version.
- Test normal, boundary, and edge cases; then document time/space complexity.

## Hands-on Coding
