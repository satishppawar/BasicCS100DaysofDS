## Basic Notes

What is Combination Sum?
- `Combination Sum` is a constraint-driven DSA problem typically solved with recursion/backtracking (or DP where applicable).
- A robust solution depends on state definition, decision choices, stopping rules, and pruning conditions.

Core theory details:
- Pattern: backtracking with repeated use allowed.
- State: start index, remaining target, path.
- Complexity: exponential search; sort helps pruning.
