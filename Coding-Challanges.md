# 80/20 Rule

Master these patterns:

- Hashing
- Two Pointers
- Sliding Window
- Prefix Sum
- Binary Search
- DFS/BFS
- Dynamic Programming
- Monotonic Stack

These alone solve roughly **80–90% of coding interview problems**.
