# Day 02 - Variables: System Defined vs User Defined

## Basic Notes

What is Variables?
- Variables can hold values of different types
- Data Type is a classification that specifies which type of value a variable can hold and what operations can be performed on it. 
- Data types are fundamental to programming, as they define the nature of data and how it can be manipulated.
- They can be broadly categorized into system-defined types and user-defined types.

**System-defined types:**
- Built-in primitives and collections provided by the language runtime
- Examples: integers, floating-point numbers, strings, lists, dictionaries, and sets

Example in Python for System-defined types:
```python
# System-defined types
x = 10  # integer   
y = "Hello"  # string
my_list = [1, 2, 3]  # list 
my_dict = {"key": "value"}  # dictionary
```

**User-defined types:**
- Custom classes/structures that model domain-specific behavior and data
- Examples: classes like `Person`, `Car`, or `BankAccount` that encapsulate both data and methods

Example in Python for User-defined types:
```python
# User-defined type
class Person:
    def __init__(self, name, age):
        self.name = name  # instance variable
        self.age = age    # instance variable

    def greet(self):
        return f"Hello, my name is {self.name} and I am {self.age} years old."
```

In this example, `Person` is a user-defined class with instance variables `name` and `age`, and a method `greet()` that returns a greeting message.
